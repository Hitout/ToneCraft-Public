打开最新 Release

文件说明

  • Android App Bundle（.aab）：用于上传 Google Play，不能直接安装到 Android 设备。
  • Android APK（.apk）：用于在允许安装外部来源应用的 Android 设备上直接安装。

安全提示

请核对 Release 页面中的版本号、SHA-256 校验值和发布日期。正式发布的安装包应使用正式的 Upload keystore 签名。
